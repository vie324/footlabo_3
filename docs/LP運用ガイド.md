# フットラボLP 運用ガイド

コードを触らずにLPの内容を変えたり、集客の計測を始めたりするための手引きです。

---

## 1. 管理シート（かんたんCMS）

LPの「残り枠」「特典締切」「お知らせ帯」「LINE予約URL」は、Googleスプレッドシートから変更できます。

- **シートURL**: https://docs.google.com/spreadsheets/d/1e27WEgd-wq2EZjdiDswOpj4XMGL2oxVRLrHpOGXPtog/edit
- シートのオーナー: info@viecompany.net（Driveの「フットラボLP 管理シート」）

### 共有設定：完了済み

シートは「リンクを知っている全員（閲覧者）」で公開済みで、LPから読み取れる状態です。以後は**セルを書き換えるだけ**で反映されます。

※もし共有設定を戻すと、LPには何も表示されなくなります（安全側の動作。エラーにはなりません）。

### 編集できる項目

| key | 例 | 説明 |
|---|---|---|
| `line_url` | `https://lin.ee/abc123` | LINE公式アカウントのURL。**LINE経由版で表示しているとき、LP内の予約ボタン（6箇所）すべてに反映**されます。空欄なら `index.html` の `LINE_URL`（現行 `https://lin.ee/ug1o1Ih`）が使われます。直予約版の予約ボタンには影響しません（→「3. 予約ボタンの行き先」） |
| `slots_show` | `TRUE` / `FALSE` | 残り枠バッジの表示スイッチ |
| `slots_month` | `8月` | 枠の対象月ラベル |
| `slots_left` | `5` | 今月の残り初回体験枠数（半角数字） |
| `deadline_show` | `TRUE` / `FALSE` | 特典締切の表示スイッチ |
| `deadline_text` | `2026-08-31` または `8月31日(月)まで` | 締切。**日付形式（YYYY-MM-DD）で入れると「8月31日(月)まで」に自動整形＋「あと◯日」バッジが毎日自動更新**されます。文章で入れた場合はそのまま表示（残り日数は出ません） |
| `notice_text` | `8/20(木)は臨時休業です` | ページ上部のお知らせ帯。**空欄で非表示** |

- 反映タイミング: 保存後すぐ（閲覧者側は最大5分のキャッシュあり。再読込で反映）
- **B列（value）には文字も数字もそのまま入力してOK**です（CSV形式で読み取るため、Googleの型自動判定の影響を受けません）
- 表示場所: 残り枠バッジ＝ヒーロー直下・特典BOX・「混み合います」欄・画面下の固定バー／締切＝特典BOX×2
- **残り枠が3名以下**になると、バッジが濃色に変わり「まもなく終了」ラベルが自動で付きます（手動設定は不要）
- 残り枠の数字は、画面に入ると0からカウントアップする演出が入ります

### ⚠️ 大事な注意（景品表示法）

残り枠数・締切は **必ず実際の数字・日付** で運用してください。実態のない「残りわずか」「本日まで」表示は景品表示法（有利誤認）に抵触するおそれがあります。迷ったら表示OFF（FALSE）に。

## 2. 計測タグ（アクセス解析・広告）

`index.html` 上部の「集客設定（かんたん設定エリア）」に **IDを貼るだけ** で計測が始まります。空欄なら何も読み込まれません。

```js
window.LP_CONFIG = {
  CTA_MODE: "direct",  // 予約ボタンの行き先（→「3. 予約ボタンの行き先」）
  RESERVE_URL: "",     // 直予約ページのURL
  LINE_URL: "https://lin.ee/ug1o1Ih",
  SHEET_ID: "（設定済み）",
  GA4_ID: "",         // ← Googleアナリティクス4 例 "G-XXXXXXXXXX"
  CLARITY_ID: "",     // ← Microsoft Clarity 例 "abcdefg123"
  META_PIXEL_ID: ""   // ← Meta広告ピクセル 例 "1234567890"
};
```

| ツール | 取得方法 | 何がわかるか |
|---|---|---|
| **GA4**（無料） | [analytics.google.com](https://analytics.google.com) → プロパティ作成 → データストリーム追加 → 「G-」で始まる測定IDをコピー | 訪問数・流入元・**予約ボタンのクリック数**（直予約版は `reserve_click`、LINE経由版は `line_click` を自動送信。どのセクションで押されたか＝`placement`、どちらの版か＝`cta_mode` も記録） |
| **Clarity**（無料） | [clarity.microsoft.com](https://clarity.microsoft.com) → プロジェクト作成 → 設定からプロジェクトIDをコピー | ヒートマップ・録画で「どこで離脱したか」（カスタムタグ `cta_mode` で直予約版／LINE経由版を分けて見られます） |
| **Meta Pixel** | Metaビジネスマネージャ → イベントマネージャ → ピクセル作成 | 広告配信の最適化・計測（予約ボタンのクリックで `Lead` イベント送信。`cta_mode` 付き） |

**Googleビジネスプロフィール**（地図検索対策）は未整備なら最優先で登録を: https://business.google.com （店舗名・住所・営業時間・写真・カテゴリ「ネイルサロン/フットケア」）

## 3. 予約ボタンの行き先（直予約版／LINE経由版）

LPは **直予約版**（予約ページへ直接）と **LINE経由版**（LINE公式アカウントへ）の2つの版を、1つの `index.html` で切り替えられます。ABテスト用に、どちらの版もいつでも表示できます。

| 設定（`index.html` 上部の `LP_CONFIG`） | 現在の値 | 内容 |
|---|---|---|
| `CTA_MODE` | `"direct"` | 通常表示する版。`"direct"`＝直予約版／`"line"`＝LINE経由版 |
| `RESERVE_URL` | `""`（**未設定**） | 直予約ページのURL（サロン1の予約ページなど）。**空欄の間は、ボタンが空振りしないよう自動でLINE経由版を表示**します |
| `LINE_URL` | `https://lin.ee/ug1o1Ih` | LINE経由版の行き先。管理シートの `line_url` でも上書きできます |

### よく使う操作

- **直予約版を公開する**: `RESERVE_URL: "https://…"` に予約ページのURLを入れる → 予約ボタン6箇所（ヘッダー・ヒーロー・特典BOX・再掲BOX・最後のCTA・画面下の固定バー）がすべて予約ページに変わります
- **LINE経由版に戻す**: `CTA_MODE: "line"` に書き換える（`RESERVE_URL` は消さなくてOK）
- **URLで版を指定する（ABテスト・確認用）**: ページURLの末尾に `?cta=line` を付けるとLINE経由版、`?cta=direct` を付けると直予約版で表示されます。`CTA_MODE` の設定より優先されます
  - 例: 広告A → `https://公開ドメイン/`（直予約版）、広告B → `https://公開ドメイン/?cta=line`（LINE経由版）
  - UTMなど他のパラメータと併用できます（例 `?utm_source=google&cta=line`）
  - `RESERVE_URL` が未設定のまま `?cta=direct` で開くと、確認用に直予約版の見た目で表示されますが、ボタンを押すと「予約ページのURLが未設定です」と表示されます。広告には使わないでください

### 版によって変わるところ

| 場所 | 直予約版 | LINE経由版 |
|---|---|---|
| 予約ボタン（6箇所） | 「Webで予約する」（ヘッダーは「Web予約」）・カレンダーアイコン・黒 | 「LINEで予約する」（ヘッダーは「LINE予約」）・LINEアイコン・LINEグリーン |
| ボタン下の一言・上の見出し | 「24時間いつでも予約OK」「空いている日時を選ぶだけ」など | 「予約は30秒で完了」「友だち追加だけでもOK」など |
| 流れる帯・数字の帯（4つ目） | Web予約は24時間OK／Web予約 24時間OK | LINE予約は30秒／LINE予約 30秒 |
| 比較表「始めやすさ」 | Web予約・当日OK | 予約30秒・当日OK |
| 予約の流れ（3ステップ） | 予約ページを開く → 日時を選ぶ → 当日、手ぶらでご来店 | 友だち追加 → 日時を選ぶ（ご希望の日時をメッセージするだけ） → 当日、手ぶらでご来店 |

それ以外（価格・特典・FAQ・営業時間など）は両方の版で共通です。`index.html` では、直予約版だけの文言に `class="only-direct"`、LINE経由版だけの文言に `class="only-line"` が付いています。

### ABテストの見方

- GA4: イベント `reserve_click`（直予約版）と `line_click`（LINE経由版）の数を、それぞれの版のセッション数で割って比較します。GA4の管理画面で `cta_mode` をカスタムディメンション（イベントスコープ）に登録すると、版ごとの集計がしやすくなります
- ボタンのクリックは「予約の手前」の数字です。最終的には、予約システム（直予約）とLINE（LINE経由）それぞれの実際の予約数・来店数で比べてください
- 比較中は、価格・コピーなど他の部分は変えないでください（どちらの効果か分からなくなります）

### LINEでの写真相談について

LINEで写真を送るだけの無料相談は**終了**したため、LP上の写真相談の案内（特典3・STEP01の一文・最後のCTA「まずは、写真を送るだけ。」など）はすべて削除しています。再開する場合は、特典・ステップ・最後のCTAの文言をあわせて戻す必要があります。

### 画像を差し替えたときの注意（WebP）

表示を速くするため、主要な画像は **WebP版（`.webp`）とJPEG/PNG版の2つ**を用意して、対応ブラウザにはWebPを配信しています。

`images/logo.png` などを差し替えたときは、**同名の `.webp` も作り直してください**（作らないと古い画像が表示され続けます）。対象は `logo` / `character` / `case1_before` / `case1_after` / `case2_before` / `case2_after` の6枚です。

**店舗写真（`shop_interior` / `shop_exterior`）はWebPを用意する必要はありません。** JPEGを1枚置くだけで表示されます（画面外で遅延読み込みされるため、WebP化の効果が小さいわりに「JPEGだけ置くと真っ白になる」事故のほうが起きやすいので、あえて外しています）。

差し替えるときは **横長10:7・幅1600px・JPEG品質82前後（1枚200KB程度）** を目安にしてください。元データのまま（数MB）置くと表示が重くなります。ファイルが無い場合は、置き場所を示すグレーの枠が表示されます。

変換は「webp 変換」で検索して出てくる無料サイト（Squooshなど）で、品質80〜85程度に設定すればOKです。

**店舗写真を実際の写真に差し替えたら**、`index.html` の `<span class="img-note">※イメージ写真です</span>`（外観・店内の2箇所）を削除してください。

※公開ドメインが決まったら `index.html` の `og:image` / `twitter:image` を絶対URL（`https://ドメイン/images/ogp.jpg`）に変更するとSNSシェアが確実になります。

### ⚠️ 症例写真の掲載について

- **掲載前に、必ずご本人の許諾**（できれば書面・LINE等の記録が残る形）を得てください。足元の写真でも、施術記録として個人に関わる情報です
- 写真は正方形（1:1）でご用意ください。CASE見出しの文言は `index.html` 内の `class="c-t"` の行で変更できます
- BEFORE/AFTERは実際の同一部位・同一条件で撮影したものを使い、加工（明るさの大幅補正・レタッチ）は避けてください（景品表示法上、誤認を招く恐れがあります）
- 症例写真はタップで拡大表示されます。拡大時のキャプションは各画像の `alt` 属性の文章です

## 5. ABテスト用コピー案

効果検証は「1度に1箇所だけ」変えて、GA4の `reserve_click`（直予約版）／`line_click`（LINE経由版）の数で比較してください（目安: 各案500セッション以上）。**直予約版とLINE経由版のテスト中は、下のコピーは変えずに、テストが終わってから**試してください。

### メインコピー（H1）
- 現行: `その巻き爪、痛みなく整える。`
- 案B（価格・全部込み訴求）: `その足の悩み、まとめて整える。`
- 案C（我慢訴求）: `その痛み、もう我慢しなくていい。`
- 案D（キャラ連動）: `巻き爪は、我慢しなくていいのだ。`

※「切らない」という表現は、実際には爪きりも施術に含まれるため全面的に取りやめています。差別化の軸は **「痛みがない施術方法」＋「巻き爪専門ケア 全部込み ¥3,980〜（巻き爪1指）」** です。

### CTAボタン
- 現行（直予約版）: `Webで予約する`

※LINEでの写真相談・無料相談は終了したため、「無料相談」「写真を送って」系の文言は使わないでください。

### 固定バー

## 6. 価格を変更する場合

巻き爪専門ケア（旧称 ALL FOOT CARE）は **補正する巻き爪の本数（1指／2指）で料金が決まる2パターン** です。右と左の両方に巻き爪がある方などは「2指」になります。フットラボAIカウンセリング（初診にあたる無料カウンセリング）はどちらも無料です。

| 項目 | 通常価格（税込） | 初回（税込） |
|---|---|---|
| フットラボAIカウンセリング | 3,300円（税抜3,000円） | **0円** |
| 巻き爪専門ケア 巻き爪1指 | 13,200円（税抜12,000円） | **3,980円**（税抜3,618円／9,220円引き＝約70%OFF） |
| 巻き爪専門ケア 巻き爪2指 | 26,400円（税抜24,000円） | **7,960円**（税抜7,236円／18,440円引き＝約70%OFF） |
| **初回合計（1指）** | **16,500円** | **3,980円**（12,520円お得＝75%OFF） |
| **初回合計（2指）** | **29,700円** | **7,960円**（21,740円お得＝73%OFF） |

※税抜価格は 税込÷1.1 の端数切り捨てです（3,980円÷1.1＝3,618.18…→3,618円、7,960円÷1.1＝7,236.36…→7,236円）。LPでは料金カードと注記（fineprint）に税抜価格を併記しています。

※「フットラボAIカウンセリング」は店舗で行う無料カウンセリング（通常3,300円）。LP上部の3問クイズは「フットラボチェック」で、別物です。当店は医療機関ではないため、LP上では「初診料」という言葉は使っていません。

**巻き爪専門ケアに含まれるもの**（巻き爪の本数による料金以外、追加料金なし）: 巻き爪／分厚い爪／変形爪／副爪／たこケア／魚の目／角質／爪きり

### 変更手順

価格表記は複数箇所に分散しています。`index.html` 内を以下のキーワードで検索して、すべて揃えて変更してください:
`¥3,980` / `3,980円` / `3,618円` / `13,200円` / `¥16,500` / `16,500円` / `¥7,960` / `7,960円` / `7,236円` / `26,400円` / `¥29,700` / `29,700円` / `3,300円` / `12,520円` / `21,740円` / `9,220円` / `70%OFF` / `73%OFF` / `75%OFF`

「12,520円お得」は **1指の通常合計16,500円 − 初回3,980円**、「21,740円お得」は **2指の通常合計29,700円 − 初回7,960円** の差額です（いずれも税込）。割引率は端数を切り捨てた実態以下の数値にしてください（1指合計の75%は実態75.9%、2指合計の73%は実態73.2%で安全側。巻き爪専門ケアの約70%は1指・2指とも実態69.9%のため「約」を付けています。厳密には69%が安全側です）。価格を変えたら差額・割引率・注記（fineprint）・JSON-LDの `priceRange` を更新してください。**`images/ogp.jpg` にも価格（1指 ¥3,980・2指 ¥7,960）が焼き込まれている**ため、あわせて作り直しが必要です。

## 7. ドクターからの一言（医師のコメント）

COMPARE（「手術」の前に、知ってほしい選択肢）のすぐ下に、フットラボをおすすめしてくださっているクリニックの医師のコメントを掲載しています。

- コメントは各クリニックに記入いただいたシートの「フットラボについて（推薦の言葉）」を**原文のまま**掲載しています。言い回しを変える・要約する場合は、必ず先生の了承を得てください

- 先生の顔写真は `images/doctor_◯◯.jpg`（正方形）を置くと自動で表示されます（無い間は聴診器アイコン）

## 8. 公開（Vercel）

- Vercel（Proプランのチーム）で、GitHubの `vie324/footlabo_3` の `main` ブランチを公開しています。ビルド不要の静的サイトで、Framework Preset は「Other」です

- `docs/`（この運用ガイド）は `.vercelignore` で公開対象から外しています。`https://公開ドメイン/docs/…` を開いても404になるのが正しい状態です
- 独自ドメインは、Vercelの Settings → Domains に表示される値（Aレコード／CNAME）を、ドメインを管理している業者に設定してもらいます。ネームサーバーの変更は不要です（メールなど既存の設定に影響が出るため避けてください）
