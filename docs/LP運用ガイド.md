# フットラボLP 運用ガイド

コードを触らずにLPの内容を変えたり、集客の計測を始めたりするための手引きです。

---

## 1. 管理シート（かんたんCMS）

LPの「残り枠」「特典締切」「お知らせ帯」「LINE予約URL」は、Googleスプレッドシートから変更できます。

- **シートURL**: https://docs.google.com/spreadsheets/d/1e27WEgd-wq2EZjdiDswOpj4XMGL2oxVRLrHpOGXPtog/edit
- シートのオーナー: info@viecompany.net（Driveの「フットラボLP 管理シート」）

### 共有設定：完了済み

シートは「リンクを知っている全員（閲覧者）」で公開済みで、LPから読み取れる状態です。以後は**セルを書き換えるだけ**で反映されます。

※もし共有設定を戻すと、LPには何も表示されなくなります（安全側の動作。エラーにはなりません）。

### 編集できる項目

| key | 例 | 説明 |
|---|---|---|
| `line_url` | `https://lin.ee/abc123` | LINE公式アカウントのURL。**入れた瞬間、LP内の全予約ボタン（7箇所）に反映**されます。空欄ならHTMLに直接書かれた現行URL（`https://lin.ee/ug1o1Ih`）が使われます |
| `slots_show` | `TRUE` / `FALSE` | 残り枠バッジの表示スイッチ |
| `slots_month` | `8月` | 枠の対象月ラベル |
| `slots_left` | `5` | 今月の残り初回体験枠数（半角数字） |
| `deadline_show` | `TRUE` / `FALSE` | 特典締切の表示スイッチ |
| `deadline_text` | `2026-08-31` または `8月31日(月)まで` | 締切。**日付形式（YYYY-MM-DD）で入れると「8月31日(月)まで」に自動整形＋「あと◯日」バッジが毎日自動更新**されます。文章で入れた場合はそのまま表示（残り日数は出ません） |
| `notice_text` | `8/20(木)は臨時休業です` | ページ上部のお知らせ帯。**空欄で非表示** |

- 反映タイミング: 保存後すぐ（閲覧者側は最大5分のキャッシュあり。再読込で反映）
- **B列（value）には文字も数字もそのまま入力してOK**です（CSV形式で読み取るため、Googleの型自動判定の影響を受けません）
- 表示場所: 残り枠バッジ＝ヒーロー直下・特典BOX・「混み合います」欄・画面下の固定バー／締切＝特典BOX×2
- **残り枠が3名以下**になると、バッジが濃色に変わり「まもなく終了」ラベルが自動で付きます（手動設定は不要）
- 残り枠の数字は、画面に入ると0からカウントアップする演出が入ります

### ⚠️ 大事な注意（景品表示法）

残り枠数・締切は **必ず実際の数字・日付** で運用してください。実態のない「残りわずか」「本日まで」表示は景品表示法（有利誤認）に抵触するおそれがあります。迷ったら表示OFF（FALSE）に。

## 2. 計測タグ（アクセス解析・広告）

`index.html` 上部の「集客設定（かんたん設定エリア）」に **IDを貼るだけ** で計測が始まります。空欄なら何も読み込まれません。

```js
window.LP_CONFIG = {
  SHEET_ID: "（設定済み）",
  GA4_ID: "",         // ← Googleアナリティクス4 例 "G-XXXXXXXXXX"
  CLARITY_ID: "",     // ← Microsoft Clarity 例 "abcdefg123"
  META_PIXEL_ID: ""   // ← Meta広告ピクセル 例 "1234567890"
};
```

| ツール | 取得方法 | 何がわかるか |
|---|---|---|
| **GA4**（無料） | [analytics.google.com](https://analytics.google.com) → プロパティ作成 → データストリーム追加 → 「G-」で始まる測定IDをコピー | 訪問数・流入元・**LINEボタンのクリック数**（`line_click` イベントを自動送信、どのセクションで押されたかも記録） |
| **Clarity**（無料） | [clarity.microsoft.com](https://clarity.microsoft.com) → プロジェクト作成 → 設定からプロジェクトIDをコピー | ヒートマップ・録画で「どこで離脱したか」 |
| **Meta Pixel** | Metaビジネスマネージャ → イベントマネージャ → ピクセル作成 | 広告配信の最適化・計測（LINEクリックで `Lead` イベント送信） |

**Googleビジネスプロフィール**（地図検索対策）は未整備なら最優先で登録を: https://business.google.com （店舗名・住所・営業時間・写真・カテゴリ「ネイルサロン/フットケア」）

## 4. 素材の差し替えルール

| ファイル | 用途 |
|---|---|
| `images/logo.png` | ロゴ（ヘッダー・ヒーロー・フッター） |
| `images/character.png` | ツメピカにゃん（ヒーロー・診断・メッセージ・キャラ紹介・フッター前） |
| `images/shop_interior.jpg` | **店内写真**（SALONセクション）。横長10:7 |
| `images/shop_exterior.jpg` | **外観写真**（ACCESSセクションの地図の上）。横長10:7 |
| `images/ogp.jpg` | シェア時のサムネイル（1200×630）。**外観写真＋価格（巻き爪1指 ¥3,980・2指 ¥7,960）入り**のため、価格改定時は作り直しが必要です |
| `images/doctor_revo.jpg` | 「ドクターからの一言」のREVO CLINIC 札幌すすきの院・宮崎院長の顔写真（正方形400×400px）。宣材写真フォルダの IMG_5165.JPG から切り抜き |
| `images/doctor_okachi.jpg` | 「ドクターからの一言」のおかちクリニック・神田院長の顔写真（正方形400×400px）。共有いただいた IMG_7776.JPG から切り抜き |
| `hero.mp4` / `step1〜4.mp4` | 動画（**ファイル名は半角英数のまま**。日本語名は文字コード問題の原因になります） |
| `images/poster_*.jpg` | 動画読込前に表示される静止画 |
| `images/case1_before.jpg` / `case1_after.jpg` / `case2_before.jpg` / `case2_after.jpg` | 症例写真（BEFORE/AFTER。同名で上書きすれば差し替わります） |

### 画像を差し替えたときの注意（WebP）

表示を速くするため、主要な画像は **WebP版（`.webp`）とJPEG/PNG版の2つ**を用意して、対応ブラウザにはWebPを配信しています。

`images/logo.png` などを差し替えたときは、**同名の `.webp` も作り直してください**（作らないと古い画像が表示され続けます）。対象は `logo` / `character` / `case1_before` / `case1_after` / `case2_before` / `case2_after` の6枚です。

**店舗写真（`shop_interior` / `shop_exterior`）はWebPを用意する必要はありません。** JPEGを1枚置くだけで表示されます（画面外で遅延読み込みされるため、WebP化の効果が小さいわりに「JPEGだけ置くと真っ白になる」事故のほうが起きやすいので、あえて外しています）。

差し替えるときは **横長10:7・幅1600px・JPEG品質82前後（1枚200KB程度）** を目安にしてください。元データのまま（数MB）置くと表示が重くなります。ファイルが無い場合は、置き場所を示すグレーの枠が表示されます。

変換は「webp 変換」で検索して出てくる無料サイト（Squooshなど）で、品質80〜85程度に設定すればOKです。

※公開ドメインが決まったら `index.html` の `og:image` / `twitter:image` を絶対URL（`https://ドメイン/images/ogp.jpg`）に変更するとSNSシェアが確実になります。

### ⚠️ 症例写真の掲載について

- **掲載前に、必ずご本人の許諾**（できれば書面・LINE等の記録が残る形）を得てください。足元の写真でも、施術記録として個人に関わる情報です
- 写真は正方形（1:1）でご用意ください。CASE見出しの文言は `index.html` 内の `class="c-t"` の行で変更できます
- BEFORE/AFTERは実際の同一部位・同一条件で撮影したものを使い、加工（明るさの大幅補正・レタッチ）は避けてください（景品表示法上、誤認を招く恐れがあります）
- 症例写真はタップで拡大表示されます。拡大時のキャプションは各画像の `alt` 属性の文章です

## 6. 価格を変更する場合

### 現在の価格構成

ALL FOOT CARE は **補正する巻き爪の本数（1指／2指）で料金が決まる2パターン** です。右と左の両方に巻き爪がある方などは「2指」になります。フットラボAIカウンセリング（初診にあたる無料カウンセリング）はどちらも無料です。

| 項目 | 通常価格（税込） | 初回（税込） |
|---|---|---|
| フットラボAIカウンセリング | 3,300円（税抜3,000円） | **0円** |
| ALL FOOT CARE 巻き爪1指 | 13,200円（税抜12,000円） | **3,980円**（税抜3,618円／9,220円引き＝約70%OFF） |
| ALL FOOT CARE 巻き爪2指 | 26,400円（税抜24,000円） | **7,960円**（税抜7,236円／18,440円引き＝約70%OFF） |
| **初回合計（1指）** | **16,500円** | **3,980円**（12,520円お得＝75%OFF） |
| **初回合計（2指）** | **29,700円** | **7,960円**（21,740円お得＝73%OFF） |

※税抜価格は 税込÷1.1 の端数切り捨てです（3,980円÷1.1＝3,618.18…→3,618円、7,960円÷1.1＝7,236.36…→7,236円）。LPでは料金カードと注記（fineprint）に税抜価格を併記しています。

※「フットラボAIカウンセリング」は店舗で行う無料カウンセリング（通常3,300円）。LP上部の3問クイズは「フットラボチェック」で、別物です。当店は医療機関ではないため、LP上では「初診料」という言葉は使っていません。

**ALL FOOT CARE に含まれるもの**（巻き爪の本数による料金以外、追加料金なし）: 巻き爪／分厚い爪／変形爪／副爪／たこケア／魚の目／角質／爪きり

### 料金の表示場所

| 場所 | 表示内容 |
|---|---|
| ヒーロー | ステッカー「¥3,980 巻き爪1指」、バッジ「全部込み ¥3,980〜」、価格ボックス（1指を大きく、2指を点線枠で併記） |
| 流れる帯（ティッカー） | 「巻き爪1指 ¥3,980」「左右両方（2指）も ¥7,960」 |
| 特典BOX・再掲BOX | AIカウンセリング無料の行＋1指／2指の料金カード2枚 |
| 選ばれる理由03・FAQ | 1指／2指の料金。FAQに「巻き爪が右と左の両方にある場合は？」を追加 |
| 固定バー | 「初回限定 巻き爪1指 ¥16,500 → ¥3,980」 |
| title・description・OGP・JSON-LD | 1指 ¥3,980・2指 ¥7,960。`priceRange` は `¥3,980〜¥26,400` |

### 変更手順

価格表記は複数箇所に分散しています。`index.html` 内を以下のキーワードで検索して、すべて揃えて変更してください:
`¥3,980` / `3,980円` / `3,618円` / `13,200円` / `¥16,500` / `16,500円` / `¥7,960` / `7,960円` / `7,236円` / `26,400円` / `¥29,700` / `29,700円` / `3,300円` / `12,520円` / `21,740円` / `9,220円` / `70%OFF` / `73%OFF` / `75%OFF`

「12,520円お得」は **1指の通常合計16,500円 − 初回3,980円**、「21,740円お得」は **2指の通常合計29,700円 − 初回7,960円** の差額です（いずれも税込）。割引率は端数を切り捨てた実態以下の数値にしてください（1指合計の75%は実態75.9%、2指合計の73%は実態73.2%で安全側。ALL FOOT CAREの約70%は1指・2指とも実態69.9%のため「約」を付けています。厳密には69%が安全側です）。価格を変えたら差額・割引率・注記（fineprint）・JSON-LDの `priceRange` を更新してください。**`images/ogp.jpg` にも価格（1指 ¥3,980・2指 ¥7,960）が焼き込まれている**ため、あわせて作り直しが必要です。

## 7. ドクターからの一言（医師のコメント）

COMPARE（「手術」の前に、知ってほしい選択肢）のすぐ下に、フットラボをおすすめしてくださっているクリニックの医師のコメントを掲載しています。

- コメントは各クリニックに記入いただいたシートの「フットラボについて（推薦の言葉）」を**原文のまま**掲載しています。言い回しを変える・要約する場合は、必ず先生の了承を得てください
- シートの「事例」タブ（神宮外苑Woman Life Clinic）は記入例のため、LPには載せていません
- 先生の顔写真は `images/doctor_◯◯.jpg`（正方形）を置くと自動で表示されます（無い間は聴診器アイコン）
- カードには先生のお名前・肩書き（例: 「神田 眞衣 院長」）とクリニック名を表示しています。お名前が分からない場合は「◯◯クリニック 医師」としてください（実名と写真はSEO上も有利です）
- 医師を追加するときは、`index.html` の `<figure class="doc">` 〜 `</figure>` をコピーして中身を差し替えます。写真のファイル名もクリニックごとに分けてください（例: `images/doctor_wakaba.jpg`）
- 下の注記「※医師個人の見解です。効果・感じ方には個人差があり…当店のケアは医療行為ではありません。」は消さないでください
